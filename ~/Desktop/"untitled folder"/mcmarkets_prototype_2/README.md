# MC Markets 原型 (第二版)

這是MC Markets交易平台註冊流程的改進版原型，專為Web端和H5移動設備優化。

## 主要功能

1. **多步驟註冊流程**：包含區域選擇、賬戶類型、個人信息和身份驗證
2. **響應式設計**：適配桌面和移動設備  
3. **監管框架選擇**：基於用戶地區提供不同的監管選項  
4. **動態內容顯示**：根據用戶選擇顯示相關信息
5. **嚴格步驟控制**：確保用戶按順序完成所有必要步驟
6. **視覺選擇反饋**：所有選項都有明確的選中狀態提示

## 版本說明
這是第二版原型，在第一版基礎上進行了以下改進：
- 更完善的監管框架選擇邏輯

- [更多改進內容將在開發過程中添加]
